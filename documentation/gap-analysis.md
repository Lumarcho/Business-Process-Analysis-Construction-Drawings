# Gap Analysis

## Current-State Gaps

The analysis identified several gaps between the existing process and the desired future state.

| Current State | Desired State |
|---|---|
| Manual workflows | Digital workflows |
| Limited document control | Centralised document management |
| Multiple document versions | Improved version control |
| Physical distribution | Digital collaboration and distribution |
| Unstructured approvals | Structured approval workflows |
| Outdated equipment | Updated technology infrastructure |

## Root Causes

The project also applied 5 Whys and Pareto analysis to investigate the causes of drawing-delivery problems.

The analysis highlighted factors including:

- Outdated computers and software
- Printer/scanner problems
- Version-control issues
- Client feedback delays
- Courier dependency
- Archiving challenges

## Business Impact

These gaps can contribute to:

- Delays
- Rework
- Inefficient communication
- Increased administrative effort
- Difficulty tracking documents
- Reduced process visibility

## Improvement Opportunity

The analysis suggests that process improvement should address technology, processes, people and governance together rather than treating technology as the only solution.
