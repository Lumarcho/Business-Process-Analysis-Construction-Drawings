# Stakeholder Analysis

## Project Context

The project analysed the process used to prepare, approve and issue construction drawings within an engineering consulting environment.

## Key Stakeholders

| Stakeholder | Role in Process | Key Interest |
|---|---|---|
| Client Representative | Provides requirements and feedback | Accurate and timely drawings |
| Project Manager | Coordinates project activities | Delivery, quality and approvals |
| Design Engineer | Develops and revises drawings | Technical accuracy and efficient workflows |
| Technician | Supports technical drawing activities | Reliable systems and information |
| Administrative Staff | Supports documentation and distribution | Document control and efficient distribution |

## Stakeholder Needs

The analysis identified the importance of:

- Clear communication
- Timely feedback
- Accurate documentation
- Effective approval processes
- Reliable technology
- Proper version control
- Efficient document distribution

## Business Analysis Perspective

Understanding stakeholder roles and requirements helped identify where process delays and information-flow problems occurred and where improvements could be introduced.
