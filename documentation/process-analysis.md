# Process Analysis

## Process Analysed

The project analysed the construction drawing issuance process from initial client engagement through to distribution of final drawings.

## AS-IS Process

The existing process included:

1. Engage Client
2. Gather Requirements
3. Draft Preliminary Drawing
4. Submit Preliminary Drawing
5. Revise Client Feedback
6. Obtain Client Approval
7. Draft Final Drawing
8. Prepare Distribution Copy
9. Send Distribution Copies

## Analysis Approach

The project used W5 process modelling to examine:

- WHAT activities are performed
- WHO performs each activity
- WHICH information and resources are involved
- WHERE activities take place
- HOW activities are performed

## Process Challenges

The analysis identified issues involving:

- Manual workflows
- Outdated technology
- Document version control
- Printing and scanning
- Client approval delays
- Physical/courier-based document distribution

## TO-BE Direction

The proposed future-state process moves toward:

- Digital workflows
- Improved document management
- Better version control
- Cloud collaboration
- Structured approval workflows
- Updated technology infrastructure
